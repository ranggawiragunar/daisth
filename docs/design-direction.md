# Daisth Visual Direction

**Warm Minimal + Quiet Depth**

Principles:
- calm
- premium
- intentional
- grounded
- modern
- spiritually subtle
- supportive, never judgmental

Use warm ivory, forest/sage greens, muted clay accents, clean typography, generous spacing, light borders, restrained depth, and subtle geometric/arch motifs.

Avoid heavy Islamic-template ornament, bright saturated green, excessive gold, neon, glassmorphism, heavy shadows, and gamification visuals.
